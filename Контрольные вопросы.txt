Ответы на контрольные вопросы

1. Чем Flexbox отличается от Grid?
Flexbox предназначен в основном для одномерного расположения элементов — в строку или столбец. Grid предназначен для двумерных сеток — строк и колонок.

2. Какое свойство Flexbox отвечает за выравнивание по горизонтали?
justify-content.

3. Как задать направление элементов в Flexbox?
С помощью свойства flex-direction:

flex-direction: row;

или

flex-direction: column;

4. Что делает свойство flex-wrap?
Оно определяет, должны ли элементы переноситься на новую строку, если для них недостаточно места.

Например:

flex-wrap: wrap;

5. Какое свойство Grid задаёт количество колонок?
grid-template-columns.

Например:

grid-template-columns: repeat(3, 1fr);

создаёт три колонки.

6. Как объединить несколько ячеек в Grid?
С помощью grid-column и grid-row.

Например:

.grid-item {
    grid-column: span 2;
}

Элемент займёт две колонки.

7. Что делает свойство gap?
gap задаёт расстояние между элементами Grid или Flexbox.

gap: 10px;

8. Как задать адаптивную сетку при помощи медиа-запросов?
Использовать @media и изменить количество колонок:

@media (max-width: 600px) {
    .grid-container {
        grid-template-columns: 1fr;
    }
}

9. В каких случаях удобнее Flexbox, а в каких Grid?
Flexbox удобен для меню, шапок, кнопок и выравнивания элементов в одну строку или колонку. Grid удобнее для сложных сеток с несколькими строками и колонками.

10. Можно ли комбинировать Flexbox и Grid в одном макете? Приведите пример.
Да. Например, в данной практической работе Flexbox используется для шапки и подвала, а Grid — для шести карточек основного содержимого.
